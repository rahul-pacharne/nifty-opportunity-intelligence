# Nifty Opportunity Intelligence

Market intelligence for Nifty 50 and Bank Nifty gap-up and gap-down opportunities. The platform can recommend a manual CALL or PUT buy. It does not place orders.

The approved baseline is `docs/PROJECT_MASTER.md`. Fictional alert examples are in `docs/SAMPLE_ALERTS.md`. Phase 0 research rules are in `docs/phase0/`. The build order is `docs/ROADMAP.md`.

```bash
python3 -m pytest
```

Python 3.10 or newer. Provider tokens belong in the environment, never in git.
